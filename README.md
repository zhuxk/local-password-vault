# 本地密码匣

一个无需服务器和构建工具的 Chrome/Edge Manifest V3 密码管理扩展。当前版本为 `0.4.0`。

上架 Chrome Web Store 与 Microsoft Edge Add-ons 的全部素材、文案与打包脚本见 [`store/`](store/SUBMIT.md)。

## 当前功能

- 使用主密码在浏览器本地创建 AES-256-GCM 加密密码库
- 保存网址、用户名和密码，同一站点支持多个账号
- 同一站点添加相同用户名时先确认是否更新，避免重复账号
- 每个站点可指定默认账号，也可继续自动选择排序后的第一个账号
- 密码更新后保留最近 3 次旧密码，可在管理页复制或重新使用
- 在当前网页选择账号并一键填充
- 在扩展弹窗分别复制账号或密码
- 单账号登录页自动填充用户名和密码，但不会自动提交
- 多账号登录页在密码框旁显示“钥”按钮，可直接选择账号
- 登录新网站时提示保存账号密码
- 已有账号使用新密码登录时提示更新密码
- 登录跳转后仍会在原标签页保留保存提示
- 自动读取并保存当前网页标题，方便在管理页面辨认网站
- 网页标题与子域名重复或标题本身是登录 URL 时自动隐藏，只展示有辨识度的网站名称
- 根域名与 `www` 共用账号，其他子域名严格隔离
- 从 Chrome/Edge 导出的密码 CSV 导入现有密码
- 搜索、编辑、删除账号以及导出加密备份
- 管理页支持快捷复制账号/密码，并可按网站、最近修改或用户名排序
- 密码生成器可设置长度以及大写、小写、数字、符号规则
- 恢复加密备份，并在替换前校验格式、主密码和密码库数据
- 删除账号先进入回收站，可恢复、永久删除或清空回收站
- 在管理页面查看或隐藏密码
- 按分组一次性删除全部账号，包括根域名的所有子域名或同一 IP 的所有端口
- 每个网站可独立选择“自动填充”“点击填充”或“禁用”
- 支持用户名和密码分两页输入的登录流程
- 支持同源及跨域 iframe、开放式 Shadow DOM 中的登录框
- 闲置 5/15/30/60 分钟自动锁定，默认 15 分钟
- 支持从扩展弹窗直接复制账号或密码
- 可修改主密码；忘记主密码时可删除密码库并重新创建或恢复备份

## 安装

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 点击工具栏中的“本地密码匣”，创建主密码。

修改源码后，在扩展管理页面点击本扩展的“重新加载”。

扩展可发布到 Chrome Web Store 与 Microsoft Edge Add-ons：

```bash
python3 tools/make_icons.py         # 生成扩展图标

python3 tools/make_privacy_page.py  # 生成隐私政策网页
python3 tools/make_screenshots.py   # 渲染商店截图（需本机 Chrome）
bash tools/package.sh --edge        # 打包出商店可上传的 zip
```

`store/` 目录存放图标、截图、隐私政策与商店文案；`store/SUBMIT.md` 是完整的发布流程，`store/LISTING.md` 包含两个商店需要填写的每一项内容与审核备注。

## 登录与保存

- 密码库已解锁并且当前站点只有一个账号时，登录页会自动填充。
- 当前站点有多个账号时，优先填充指定的默认账号；未指定时使用排序后的第一个账号。点击密码框旁的“钥⌄”按钮可选择其他账号。
- 网站从二维码、扫码等方式切换到账号密码登录时，会重新识别并填充刚显示的输入框。
- 动态登录框出现后会进行短时重复扫描；单账号和多账号都会自动填充，多账号可通过下拉按钮切换。
- 只想手动填充或不希望某站点参与识别时，可在扩展弹窗或管理页修改该站点的填充方式。
- 两步式登录会短暂保存第一页的用户名，并在第二页匹配对应账号；该信息会在过期、锁定或关闭标签页时清除。
- 扩展只负责填充，不会自动点击登录按钮。
- 提交未保存的账号密码后，网页右上角会询问是否保存。
- 密码更新提示只针对识别到的登录表单，不识别修改密码或重置密码页面。
- 密码库锁定时只短暂保留本次登录信息；解锁后再比对，相同账号不会提示，新账号或新密码才提示保存或更新。
- 如果密码库处于锁定状态，可打开扩展或密码管理页面解锁；需要保存或更新时，网页会自动显示相应提示。

## 导入浏览器现有密码

浏览器出于安全限制，不允许扩展直接读取其密码管理器。请在 Chrome/Edge 密码管理器中使用“导出密码”，然后在本扩展的“管理全部密码与导入”页面选择 CSV 文件。

CSV 是明文文件。导入完成后应立即从磁盘和回收站中删除它。

## 加密备份与恢复

- “导出加密备份”得到的 JSON 仍是 AES-256-GCM 密文，可以用于迁移或灾难恢复。
- 在首次创建、锁定页面或已解锁的管理页都可以选择“恢复加密备份”。
- 恢复时需要输入该备份对应的主密码；已有密码库时还要明确确认替换。
- 恢复始终采用全量替换，不进行预览、合并或局部恢复。
- 修改主密码后，旧备份仍使用旧主密码，建议立即重新导出一份新备份。

## 域名规则

- `example.com` 与 `www.example.com` 视为同一站点。
- `admin.example.com`、`shop.example.com` 等其他子域名各自独立。
- 普通域名的协议、端口、路径和查询参数不参与账号匹配。
- 相同 IP 地址归入同一个管理分组，分组内按有效端口分别展示和匹配。
- 例如 `192.168.1.10:80`、`192.168.1.10:443`、`192.168.1.10:8080` 在 `192.168.1.10` 分组下作为三个独立站点。
- IP 地址未显式填写端口时，HTTP 使用 `80`，HTTPS 使用 `443`。
- 管理页面采用三级结构：根域名或 IP 分组 → 子域名或端口站点 → 账号列表，同一个子域名不会重复显示。
- 根域名识别使用随扩展附带的完整 Public Suffix List，例如 `foo.github.io` 与 `bar.github.io` 不会错误归到同一组。
- 管理工具栏在页面滚动时自动吸附到顶部，删除账号或分组后保持当前浏览位置。

## 当前限制

- 数据仅存储在当前浏览器，尚未接入 NAS 或跨设备同步。
- 不会自动提交登录表单。
- 封闭式 Shadow DOM 和非常规 Canvas 输入框无法由扩展读取；iframe 与开放式 Shadow DOM 已支持。
- 主密码无法找回；忘记后只能删除无法解密的密码库，或用已知密码的加密备份恢复。
